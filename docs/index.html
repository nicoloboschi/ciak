ciak is a screen recorder for macOS where an agent does the editing: cuts, zooms on clicks, captions, titles, narration in your own voice, the final export. Every edit is a plain file and a command. No timeline.

Timelines are for people. Agents need files.

Video editors hide every decision behind a timeline that an agent can't use. ciak keeps every decision where an agent can read it, change it and render it again.

📄
Edits are files

Each recording is a folder: the video, a project JSON with cuts, zooms, speed and background, the cursor log and captions. Same inputs, same video.

🎙️
One file, one audio track

Mic and system sound are mixed into the video's only track, so the voice never goes missing from the export.

How it works

You record and review. Everything in between is your agent.

Record

⌘2 records an area or a window. Or your agent records itself in a browser with your logins, or in a real terminal, with secrets blurred.

Edit

When it stops, idle time is cut and every click gets a zoom. Then ask your agent for the rest: captions, speed, vertical, a sunset background.

Review

The panel plays the edit live. Flip a switch and see it at once. Copy the final video straight into a chat.

Tell your agent. It knows ciak.

After a recording, the panel gives you the project id. Then just ask.

“Use /ciak to edit project 3f9a1c2e: cut the pauses, zoom less at 0:20, make it vertical.”Edit a recording
“Record yourself signing up on our staging site, then make a 30 second launch video narrated in my voice.”Record and make a film

Commands, not clicks

What your agent runs. Every command prints JSON.

# an agent records itself in a browser with your logins
ciak browser https://app.example.com
ciak start --browser --name demo
ciak browser click "New project"
ciak stop                               # idle time cut, zooms on clicks

# edit and render
ciak edit demo --speed 1.5 --background sunset
ciak captions demo
ciak render demo                        # one video + one audio track, checked

# launch videos, in your own voice
ciak voice add me
ciak film launch.film.json

Install

macOS 15+ on Apple silicon, with Xcode command line tools, Node 22+, ffmpeg and uv.

git clone https://github.com/nicoloboschi/ciak && cd ciak
npm install
./ciak install

This adds ciak to the menu bar (⌘1 screenshots, ⌘2 quick recording), the ciak command and the agent skill. macOS asks once for Screen Recording: allow ciak.
